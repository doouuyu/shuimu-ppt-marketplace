# 水木医蓝模板指南

## 视觉规范

- 画幅：16:9 全画幅；页面图片无边距铺满。
- 主色：深海军蓝 `#082C4C`、医疗蓝 `#176AA6`。
- 高光色：清透蓝 `#55B4D9`；冷青 `#78C5C1` 仅用于少量状态或细线强调。
- 底色：白色 `#FFFFFF`、浅蓝灰 `#DCEAF2`、白到浅冰蓝轻渐变。
- 字色：标题使用深海军蓝或白色，正文使用深蓝灰；仅关键数字与状态使用高光色。
- 中文字体观感接近微软雅黑或思源黑体；标题粗体、正文端正，页面字号层级不超过三级。
- 装饰语言：流动数据光线、水纹曲线、点状星轨、建筑轮廓线、轻薄线性图标、极淡医学或科技网格。
- 深色页只用于封面、章节强调或收官；普通内容页以白到浅冰蓝为主，保持大面积留白。
- 不使用 Logo、院徽、水印、页码、伪造医院照片、厚重 3D、廉价霓虹、互联网 UI 卡片堆叠或装饰性英文。

## 图片版制作规则

1. 参考页只提供视觉语言和版式角色，不自动授权复用其中的具体事实、文字、数据或机构名称。
2. 每页只承担一个主要叙事任务；标题应像汇报者会直接说出的结论。
3. 原文件为图片参考，不能宣称其中有原生标题对象。图文混排按参考生成独立配图并放原生文字；纯图片生成整页；原生流程在当前演示文稿内按参考排布必要页面，不另建独立模板。
4. 一页一次生成。全套页面复用相同的风格前缀、颜色、字体层级和安全边距。
5. 数据、日期、百分比、专业缩写、机构名称必须逐字核对；没有来源时不得生成示例值冒充真实结果。
6. UI 与仪表盘只做概念性示意，除非用户提供真实截图或数据；不得伪造真实医疗记录或临床证据。
7. 医院、团队或会场照片必须由用户提供或有可靠来源；缺少素材时使用抽象线稿，不生成假照片。
8. 交付前逐页检查：无错字、乱码、残留占位符、Logo、水印、页码、贴边、遮挡或明显风格漂移。
