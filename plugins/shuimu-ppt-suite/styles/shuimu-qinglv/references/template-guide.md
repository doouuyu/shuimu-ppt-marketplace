# 保留的原始模板角色

## 视觉规范

- 画幅：16:9，1280×720 等比画布。
- 主色：深青绿 `#3A8F96`、墨青 `#2C7175`。
- 辅色：水木绿 `#8BBD9C`、浅青 `#7AB39B`、雾青 `#CBE2DA`、白色 `#FFFFFF`。
- 中文正文优先保留微软雅黑；模板中已有思源黑体、黑体或华文中宋时保持原字体，不主动替换。
- 保留北京清华长庚医院标识、建筑线稿、圆角图像和青绿渐变页眉。不得重绘、伪造或替换为近似标识。
- 使用继承对象完成编辑。除非用户明确要求改变品牌，不新增与模板不一致的卡片、按钮、胶囊、阴影或装饰体系。

## 组稿规则

1. 每页只承载一个主要信息角色。
2. 默认使用“封面 → 目录 → 章节页 → 内容页 → 结束页”的节奏。
3. 内容页不足时重复使用最匹配的源页面；不得凭空创造一套与模板无关的页面视觉。
4. 没有合适内容槽时，图文混排可继承原标题栏并在安全区重排正文；纯原生模板流程优先换匹配源页。不把新文本框盖在旧占位符上。
5. 替换图片时保留原裁切比例、圆角和遮罩。缺少真实素材时可以使用明确的场景示意或科技插图，不冒称真实医院、人员或医疗证据。图文混排的生成配图按流程要求完成。
6. 所有页码、日期、页脚和医院标识都要逐页核对；隐藏的空结构占位符也要填充或删除。
7. 交付前渲染全部页面并检查首尾页、章节编号、目录顺序和第 7 页边界。
