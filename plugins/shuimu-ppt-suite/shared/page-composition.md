# 从内容到视觉的通用设计

本规则指导图文混排的设计判断，也供原生模板模式在其编辑边界内使用。每次根据内容和用途形成构图，不绑定某个历史样稿或固定页面家族。用户指定的参考可用于理解本次构图与视觉语言，明确要求沿用的模板及品牌对象仍优先保留。

## 信息任务先于对象清单

先回答观众要理解什么、哪些信息必须一起看、哪些需要比较或连接，再决定视觉重心、阅读方向和各模块的相对空间。区分必须上屏和可进备注的内容，未经授权不删事实、必要数据或增减页数。
背景、内容图形、文字容器和点缀共同设计。统一色调提供连续性，但一张背景图不能替代其余设计。主次可通过位置、面积、字重、色彩和密度建立，不靠把所有文字都放大加粗。克制配图应控制对比和注意力分配，仍须保留内容需要的空间、层次与业务图解。
框并非每段文字的默认外壳。确需容器时，根据它承担的分组、强调、承载或空间连接任务确定外观：直边/曲边、开放/闭合、平面/立体、边缘厚薄、材质与明暗，以及与邻近图像的连接和淡出。

## 文字容量与视觉外观联合决定

先用实际文案估算字体、行数、行宽和内边距；同时考虑图形焦点和负空间，形成可容纳文字的区域。多文字可用较平静的大承载面与清晰分区，少文字可与主体融合、使用更强的轮廓或材质，但不按字数机械选工具。
保持必要文本完整；容纳不下先调整模块大小、分区、换行与重复说明，再检查素材是否需要重做。不得用自动缩字维持一个不合适的框。

## 按视觉任务选择制作方式

| 选择 | 适用条件 | 实现边界 |
| --- | --- | --- |
| 原生 native | 简洁平面、需精确对齐或伸缩、数据变化频繁 | 原生文字、表格、图表、形状和连接 |
| Image image | 复杂轮廓、材质、光感、主体插画或空间融合 | 图像独立可替换；需要编辑的字与数据留在原生层 |
| 混合 hybrid | 容器需要图像质感，内容及关键关系仍要编辑 | Image提供底板、图形或场景，原生层放文字、数据与精确连接 |

同一个模块可以同时包含多种视觉元素。业务节点的意义由文字、数据和关系表达，其外观不必一律是原生矩形。装饰连线可由Image表现；决定精确先后、数量或方向的连接默认原生，防止图像生成改变业务含义。
纯原生模板模式仍以原生主体和框架为主，Image仅按用户要求作辅助；图文混排可将主体、容器与场景联合设计成无字视觉层，再叠加原生内容。调用范围由内容和编辑需求决定，不设数量配额；优先生成可直接进入成品的素材，减少重复转换与返工。

## 限制按素材用途生效

- evidence：真实车辆、设备、现场或证据截图，使用可追溯的真实素材，不用生成图冒充
- illustration：解释概念或方案的示意图，可用Image；不宣称为已实现成果
- decoration：主题点缀、轮廓、材质或氛围，可以生成车辆、火车等主题形象
- container：用于承载原生内容的素材框、背景面板或组合框架，可用Image并明确文字安全区

例如“车辆实拍不用AI效果图”限制真实车辆记录；不自动禁止示意车辆、装饰剪影或列车主题素材框。模糊要求只在会改变结果的地方澄清，不能自行扩大禁止范围。

## 生成与校准

图文混排的生成提示词提供本页准确文案与完整画面意图，包含图文关系、风格、目标比例、主次位置、边缘融合、文字容量与安全区，同时明确图片内不输出原生文字和精确数据图形。禁止只说“科技风背景”或只给一组空框坐标；原生模板的辅助配图按其所需上下文生成。
图文混排默认直接生成正式无字视觉层，无须先做整套纯图片 PPT。复杂且未解决的构图可以先探索少量代表页；整页设计是必要的思考，带字视觉试稿是按需采用的工具。
先做当前页面所需素材，组装后检查整体，再复用合适的部件。实际素材安全区与计划不一致时更新布局，文字放不下时调整画面或重生成相关素材，不将整页图片加隐藏文本伪装成可编辑稿。

## 验收设计决定

逐页检查：第一视觉重心是否明确；背景、容器和内容是否融合；文字是否具有合适的承载面；同组是否靠近、异组是否分开；关系是否清晰；装饰是否产生冲突或遮挡。没有样稿也必须做这些判断。
原生与Image的选择、元素归属、安全区和真实性可由程序核查；视觉统一、节奏与完成度须查看实际渲染。缺项回到相应决策修改，不能把“有图片”“没有溢出”或“检查通过”作为好看的证据。
