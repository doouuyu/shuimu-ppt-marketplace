# 复用模板与按需适配

风格是视觉选择，模板是已有文件。蓝色或科技风需求不自动产生“先建设一套模板”的任务。

1. 优先直接复用用户指定原稿或已有风格资源
2. 清华长庚绿图文混排的封面/内容页参考已认可成稿；目录、章节与结束页可用保留的原模板对应页
3. 清华长庚蓝已有套件资源时直接使用；需要其他蓝色外观时，只在本次演示文稿里适配所需封面、标题栏、配色和装饰
4. 缺少特定颜色模板时沿用合适的原生品牌结构，在本次页面中调整并如实记录来源；不要先产出独立模板PPTX、补齐整套角色或分派模板建设任务
5. 只有用户明确要求建立可复用模板时才交付一套新模板。此前已保存的模板可继续使用，不重复建立

原生封面、标题栏、Logo及实际品牌结构从源件复制。封面主题大字、报告全称和署名各有明确替换目标；清理示例文字时不能留下空的主题大字区。
标题栏原有白字、渐变、Logo和结论条按选定参考保留，视觉检查结合实际背景；不为了统一阈值把模板标题全部改黑。
正文继承安全区并重排必要内容，清理示例数据和妨碍图文的大幅重复院徽；装饰背景与真正的品牌背景按设计保留。

每个目标页记录真实来源页、复用方式与保护对象。复制原页后填写内容，导入/导出和层级兼容在代表页阶段解决一次，不能等整套完成后再恢复源对象。
恢复原生 DrawingML 和媒体时保留源层级、裁切、透明度及关系，避免图片/色块盖住文字。用同一最终文件的渲染与源页对照，声明、哈希或对象数量不等于视觉保真。
