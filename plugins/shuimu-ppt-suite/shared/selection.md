# 制作流程与风格选择

只提供三种制作选择：`ppt-image-deck` 纯图片、`editable-ppt` 图文混排、`native-template-ppt` 纯原生模板。
默认图文混排，默认风格清华长庚绿。风格、颜色、机构名和参考图不改变用户所选制作流程。
仅说“可编辑”默认图文混排；明确“纯原生模板/主体全部原生”才选原生流程。
“纯图片 + 原生封面/标题栏”仍属于纯图片流程。

风格资源见[目录](../styles/catalog.json)，读取所选指南与真实文件，不加载所有风格。
清华长庚蓝/绿原则上复用对应原生封面和标题栏。使用已有资源，颜色或科技风需求不自动触发独立模板建设；只在当前稿适配需要的页面，规则见模板复用说明。
用户提供并明确指定的实际模板优先于同名内置模板；保护范围见[模板复用](template-reuse.md)。
样式优先级：本次用户明确要求 > 明确选用的模板与风格资源 > 流程默认要求 > 附件样式建议。
附件用于内容、页序与信息关系；其字号或配色不自动覆盖用户选择与默认风格。具体来源核对见[样式规则](style-priority.md)。
旧的风格 Skill 名作为风格别名理解，不作为新制作分支。旧 `$shuimu-ppt` 或“PPT Image”泛称使用默认图文混排；旧 `$ppt-design-brief` 理解为只要设计，交付范围以当前请求为准。
自定义风格按用户描述/真实参考落实，不因为未列入目录而拒绝。

解析辅助工具相对插件根目录执行，默认值由 catalog.json 统一提供：

```bash
python shared/resolve_selection.py --workflow 图文混排 --style 清华长庚蓝
```

风格目录的 visual_description 只描述外观，不包含是否烧录文字或是否原生的流程规则。图文混排生成素材时添加无字要求；纯图片生成整页时添加准确画面文字；原生模板的配图范围由提示词决定。
