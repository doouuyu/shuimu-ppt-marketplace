# 共用需求与逐页设计

各制作流程共同使用本步骤，不再单独成为用户选择的制作 Skill。
先判断交付范围：只要设计文档/先等确认时，到设计为止；已要求制作时自检后直接继续，不新增确认门槛。
已有完整逐页设计沿用内容、页序、图文信息关系，补齐本次风格、装饰、配图提示词和排版后再制作；只有内容Markdown不代表制作设计已完成。局部修改不扩大为整套重做。
风格按[选择规则](selection.md)锁定，默认清华长庚绿；制作方式默认图文混排。参考模板和正文内容分别记录。

## 内容与逐页计划

完整读取用户材料、当前补充和实际参考，确定主题、受众、用途、必须保留的内容、数据/来源、页数与编辑性。
只有缺项会实质改变结果时才集中澄清，等待期间继续独立工作。缺少指定模板不阻断只做内容设计。
按稳定页面 ID P01…PNN组织，每页承担明确的信息任务，目录只导航，后续不重复充分讲过的内容。
每页写标题、必要的副标题/结论、完整正文、布局、风格颜色、强调位置、主图和点缀的对应关系。
文字精简但保留具体工作、数据及关系，正式客观，不用自问自答与“不是……而是……”，不加句末标点。
主图大、字号清楚、方正对齐，中文优先微软雅黑；数据来源与真实/示意身份如实记录，不编结果。
未提供的真实截图、照片或数据按用户要求处理，不能把生成示意当真实成果。

设计详细字段见[逐页设计格式](design-document-format.md)，按任务需要使用，不为凑字段制造副标题或重复文案。
只要PPT时内部设计保留必要的结构化清单与提示词，不默认交付额外总结文档；明确要Markdown时输出所需设计。
已确定流程后直接衔接对应 Skill；旧名称只作为风格/设计意图别名，不再进入旧分支。

制作顺序固定为：确定范围与风格 → 完成逐页设计文档及布局/素材计划 → 检查并保存设计版本 → 生成所需图片 → 按设计组装 → 检查与局部修复。不能先生图或写整套组装代码，再反向补设计清单。截取前N页时只处理原稿对应页面，不擅自补结束页。
