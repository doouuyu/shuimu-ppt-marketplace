# 水木青绿图片版模板指南

## 标题栏来源与几何

- 唯一来源：`assets/reference.pptx` 第 4 页。
- 参考画布：1280×720，16:9。
- 标题栏底色对象：`单圆角矩形 6`，位置约为 x=0、y=0、w=1280、h=77.73。
- 标题文本框：`文本框 3`，原占位文字为“此处输入小标题”，左边界约 22.47，顶部约 8.13。
- 医院 Logo：右上角原始图片，位置约为 x=980.93、y=15.60、w=279.73、h=48.07。
- 汇总时只保留以上三个标题栏对象，删除来源页其余示例内容；主体图片通过 OOXML 图层调整移动到三个
  标题栏对象下方，不重新绘制标题栏。

不得重新绘制、生成、描摹或替换医院 Logo。标题栏必须通过导入保留的参考 PPTX 继承。

## 图片安全区

- 图片尺寸固定为 3840×2160。
- 普通内容页顶部 0—240 px 为严格标题安全区。
- 主体文字、图标、图表、照片和装饰从 y≥270 px 开始。
- 安全区使用纯白或与主体连续的极浅背景；不生成标题、Logo、页码或装饰性英文。
- 安全区与主体之间不放阴影、下划线、横线、边框、色带、发光、渐变断层或明显分区。
- 图片仍以全画幅方式铺满幻灯片；安全区随后被原生标题栏覆盖。

## 视觉规范

- 主色：深青绿 `#3A8F96`、墨青 `#2C7175`。
- 辅色：水木绿 `#8BBD9C`、浅青 `#7AB39B`、雾青 `#CBE2DA`、白色 `#FFFFFF`。
- 中文字体观感接近微软雅黑或思源黑体；标题与正文层级清晰，每页不超过三级字号。
- 使用充足留白、轻薄线性图标、医院建筑线稿和克制的医疗学术汇报气质。
- 不使用厚重 3D、互联网 UI 卡片堆叠、廉价霓虹、伪造医院照片或无来源医疗数据。

## 页面角色

- 普通内容页：`header: true`，图片顶部留出安全区，汇总时覆盖原生标题栏。
- 封面、章节页、结束页：默认 `header: false`，图片可使用完整画布；不得让图片模型生成医院 Logo。
- 若特殊页面也明确要求普通标题栏，可设置 `header: true`，并遵守同一安全区规则。

## 可编辑性

- 可编辑：原生页面标题文本框。
- 保真但通常不应修改：原始医院 Logo、标题栏底色与几何。
- 不可逐项编辑：主体图片中烧录的正文、图表、图形和照片。
