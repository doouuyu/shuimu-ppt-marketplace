# 纯原生模板 PPT

阅读[共用需求设计](../../shared/design-brief.md)、[选择规则](../../shared/selection.md)与[通用视觉设计](../../shared/page-composition.md)，锁定内容、页序、选定风格和实际模板。
未指定风格使用清华长庚绿。清华长庚蓝/绿默认复制原生封面和标题栏；用户提供模板并要求完全沿用时，该模板决定视觉，按本次内容设计模板中允许调整的区域。

实际制作时按[实时进度接入](../../shared/live-progress.md)探测本机 PPT Live 配置；已配置则先注册完整页序，逐页发布制作状态、实际素材及原生整页渲染。单页检查后再发布通过状态；未配置跳过同步，模板与终稿检查继续保留。

## 整页设计

先确定完整上屏文案、视觉重心、主次分区、阅读顺序与业务关系，再选择模板版式和原生对象。按文字容量和阅读关系确定构图，不因主体可编辑就简化成文字清单或等重方框。
按[样式优先级](../../shared/style-priority.md)、所选风格和[字号规范](../editable-ppt/references/projection-readability.md)检查 Markdown 的设计。保留明确指定的模板样式，修正未被明确要求保留的不合适字号、配色、间距和换行。
复杂代表页可以先做完整视觉稿，但它只作参照，不作为最终主体或必经步骤。先写设计再探索视觉；已有素材按当前用途与比例判断是否复用。原生模式追求相同的层级和构图完成度，不要求复刻位图的每个像素。

## 模板与配图

从[风格目录](../../styles/catalog.json)读取所选指南，查看实际源页。检查模板是真正的原生对象还是整页图片。
缺少指定颜色模板时，按[模板复用规则](../../shared/template-reuse.md)在本次稿中适配需要的页面，不另建一套模板；整页图片不能称为原生模板。
按页面信息任务安排少量配图，主体、框架和业务连接保持原生。提示词决定是否需要图片、用途和数量；明确不需要时允许无图片。
已有真实素材优先复用，需要新增配图时读取 imagegen Skill，用内置 Image 生成符合模板气质的独立素材。
不套用图文混排的正文主图覆盖要求，不为满足生图数量破坏原生模板。

## 制作

先完成逐页设计文档及素材计划，构图确定后落实实际字号、颜色、坐标与层级，再准备图片和组装。素材到位后测量文字并校准位置，最终布局在组装前保存。只截取前N页时保留原页序，不额外补结束页。

读取 presentations 的 implementation、API quick start、template_following 与 finalization，调用 load_workspace_dependencies。
导入模板并复制匹配源页，替换原生文字、表格、图表和图片；按用户指定范围保留封面、标题栏、Logo、背景、母版及位置。
以原生内容实现已定的分区、空间层次及主线，落实本次设计的阅读顺序和图文比例。关系节点与连线一起调整，不能用装饰线代替语义；不要将整页图或主体截图当作原生内容。
真实数据与原生图表对应，清理示例内容，内容超长先调整布局，不自动缩成小字。
先用本次代表页检查整页效果与模板兼容，再扩展其余页面，不额外增加用户确认环节。
按用户页序导出到唯一小写 `out/`，重导入最终文件并逐页渲染；与源页比较模板结构，并按本页设计核对主次、比例、字级和连接关系。
在独立副本修改实际文字、金额或图表并回读，确认编辑后排版稳定。事实、字号、裁切及编辑性检查通过后仍须完成视觉检查；不以对象数量证明设计合格。说明实际模板与图片范围，不承诺像素级一致。
