# 纯原生模板 PPT

阅读[共用需求设计](../../shared/design-brief.md)与[选择规则](../../shared/selection.md)，锁定内容、页序、选定风格和实际模板。
未指定风格使用清华长庚绿。清华长庚蓝/绿都复制原生封面和标题栏；用户提供模板并要求完全沿用时，该模板决定视觉。

## 模板与配图

从[风格目录](../../styles/catalog.json)读取所选指南，查看实际源页。检查模板是真正的原生对象还是整页图片。
缺少指定颜色模板时，按[模板复用规则](../../shared/template-reuse.md)在本次稿中适配需要的页面，不另建一套模板；整页图片不能称为原生模板。
默认少量配图点缀，保持简单干净。提示词决定是否需要图片、用途和数量；明确不需要时允许无图片。
已有真实素材优先复用，需要新增配图时读取 imagegen Skill，用内置 Image 生成符合模板气质的独立素材。
不套用图文混排的正文主图覆盖要求，不为满足生图数量破坏原生模板。

## 制作

先完成逐页设计文档及素材计划，再准备图片和组装。只截取前N页时保留原页序，不额外补结束页。

读取 presentations 的 implementation、API quick start、template_following 与 finalization，调用 load_workspace_dependencies。
导入模板并复制匹配源页，替换原生文字、表格、图表和图片；保留封面、标题栏、Logo、背景、母版及位置。
以原生内容为主体，保持简洁留白，不因某种风格增加整套复杂大图。
真实数据与原生图表对应，清理示例内容，内容超长先调整布局，不自动缩成小字。
按用户页序导出到唯一小写 `out/`，重导入最终文件并逐页渲染；与源页比较模板结构，核对事实、文字、字号和裁切。
在独立副本修改文字或图表并回读确认编辑能力。说明实际使用的模板、源页和少量图片的用途。
