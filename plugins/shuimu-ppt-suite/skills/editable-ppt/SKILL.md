# 图文混排 PPT

默认图文混排与清华长庚绿。先设计、后生图、再组装，保留检查。不要把一次做好理解为省略检查，也不要依赖做完整套后再反复重排。

## 1. 确定范围和实际视觉

读取[共用设计](../../shared/design-brief.md)、[选择规则](../../shared/selection.md)，只读取所选风格的实际资源。
用户已有 Markdown 时，它是内容输入；先补齐模板、装饰、素材和排版决策，不能仅因已有 Markdown 就直接生图。
只做前 N 页时，保留原页序及对应内容，不另补封面、目录或结束页，不把 N 当成全局默认页数。

从[风格目录](../../styles/catalog.json)查看真实原稿和预览。清华长庚绿的图文混排以[已认可成稿](../../styles/shuimu-qinglv/assets/approved-reference.pptx)及[预览](../../styles/shuimu-qinglv/assets/approved-preview.png)为视觉基准：原生封面与标题栏、连续的科技装饰背景、清晰正文及结论条。
读取[模板绑定](references/template-binding.md)。颜色或“科技风”不触发独立模板建设；优先用已有资源，必要时只在当前演示文稿里适配所需封面/标题栏。

## 2. 生图之前完成设计

按[设计文档要求](references/design-documents.md)先保存一份完整 `design/PPT设计文档.md`，再形成它的结构化排版副本 `design/layout.json`。已有等价文件补齐缺项即可，不重复写三套正文。
文档逐页确定内容、背景装饰、主体是否需要配图、具体提示词、图文位置和原生对象分工；封面的主题大字与报告全称分别落实到实际文字槽。
此时 `layout.json` 必须已存在且可读取，使用 `design_contract_version: 2`。禁止由组装代码完成绘制后反向生成它，不能把代码产出的清单当作生图前设计。

```bash
python "$SKILL_DIR/scripts/design_snapshot.py" freeze <项目>/design/layout.json --design <项目>/design/PPT设计文档.md
```

此步骤检查计划并保存设计快照，不要求用户再次确认。未通过先修设计；执行任务前先稳定 Skill 与设计，不能一边改变规则一边启动整套制作。

## 3. 按设计准备素材

读取[视觉与素材要求](references/visual-and-content-quality.md)。科技装饰和内容配图分开安排：装饰背景负责整套风格，主体图负责解释内容，表格/流程页可以以原生内容为主体。
复用风格包中已经验收的无字背景和相关插画。需要新增素材时读取 imagegen Skill，使用内置 Image，直接提交设计文档中对应提示词；不得临时换成孤立大图标、玻璃构件或另一套图像风格。
图片须符合预定区域、比例、主体位置与边缘融合方式。可编辑文字、数据和标签不烧入新图；真实图像保持来源边界。
先准备代表页需要的素材并组装检查，通过后再补全其余页面的素材；全部页面设计仍须预先完成。查看每项新增图，合格后登记实际路径、尺寸、生成来源和状态。设计变动先更新文档与清单、刷新快照；只处理受影响素材，不重生成已合格的共用背景。

## 4. 从设计组装

读取当前 presentations 的本地实现、原生模板复用与导出文档，使用已验证的模板复制和组装方式。具体规则见[组装与检查](references/build-and-review.md)。
构建入口读取已锁定的 layout.json，不在源码里重新维护全部逐页文案和坐标；优先复用版式/组件，不为每份报告重新写一套大程序。
先用本次实际页面中的封面、数据页和图文页检查模板兼容及风格效果，再扩展余下页面。没有对应角色时不新增页面；此为内部检查，不默认增设用户批准环节。
原生封面及标题栏保持源结构，原生文字、数据图表和必要图形可编辑，图片独立可替换。普通正文沿用风格装饰层，不强迫每页另放一张主图。

```bash
python "$SKILL_DIR/scripts/design_snapshot.py" verify <项目>/design/layout.json
python "$SKILL_DIR/scripts/validate_deck.py" <项目>/design/layout.json --require-assets --pptx <项目>/out/<方案名>.pptx
```

## 5. 保留检查，限定修复范围

交付前检查内容与源文、原生对象、真实播放顺序、最终逐页渲染、模板对照及编辑回读。
检查科技装饰是否实际出现、封面大字是否完整可见、图文是否融合；计数和“XML存在文字”不能替代查看页面。
只改一页就复查该页及关联预览；全局模板/字体变动才复查受影响的一组页面。先回到设计定位原因，不无计划地重做整套。
PPT、渲染、PDF与预览统一引用一份记录了哈希的最终文件，不混读旧目录。输出唯一小写 out，保留必要设计、素材和构建源码；无请求不另交规划/总结文档。
