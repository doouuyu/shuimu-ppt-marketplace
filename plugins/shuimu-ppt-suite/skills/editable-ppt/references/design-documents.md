# 三份设计文档的交付规范

## 共同约定

页面 ID 为 P01、P02……；素材 ID 为 A001、A002……；元素 ID 如 P02-title、P02-chart1。
图像素材可被不同元素引用，同一对象 ID 只能出现一次。用户指定页数时不额外增加封面或目录。
默认画布 1280×720 px，几何原点左上，x 向右、y 向下；字号以 pt 写明。可按用户模板改画布，必须
整套一致，不能混用 px、pt、百分比的裸数字。几何 px / 96 = inch；pt × 96/72 = API px 字号。

## 01-逐页设计.md

文档首部记录：源材料、受众/目的、页数、主题依据、画布尺寸、颜色 tokens、已确认字体及回退字体。
字体默认可从本机可用的中文黑体中选择，封面如需宋体选择实际安装字体，不仅写“类似微软雅黑”。

每页记录：

- 页面 ID、角色、标题、希望表达的事实或观点及来源。
- 完整画面文案，包括标题、正文、标签、单位、脚注；对需保留原文的部分不缩写。
- 页面结构：主区域与辅助区域、主视觉占比、阅读顺序、信息密度。
- 初步素材 ID、需要原生绘制的图表/流程/表格。
- 可编辑性边界：哪些是原生文本/图形，哪些是图片，以及保留原截图的理由。

完成此文档后先核查内容覆盖与页序，再拆后两份文档。不要先生成整页图片再 OCR 拆字。

## 02-素材设计.md

每页列出素材，即便某页无需图片也写“Pxx：无需位图素材”。每项至少包括：

| 字段 | 要求 |
| --- | --- |
| 素材 ID / 使用页面与元素 | A001 → P02-image1 |
| 类别与来源 | 用户照片、真实截图、公开资产、AI 插图、背景纹理；标明路径或来源 URL |
| 画面用途 | 解释哪个具体概念；不得泛写“科技感配图” |
| 输出要求 | 文件格式、目标像素宽高、长宽比、透明或纯色背景；目标显示尺寸的至少 2 倍采样 |
| 主体与构图 | 主体大小/位置、方向、镜头、光照、统一色调、哪些区域必须空白 |
| 独立完整提示词 | 只生成这个素材，不出现页标题/正文/数字/标签；复杂科学插图标注另放原生文字 |
| 裁切和锚点 | contain/cover，焦点位置、允许裁切范围；图内结构标签的归一化锚点 |
| 状态与实物 | planned/generated/accepted，实际路径、像素尺寸、透明验证、版本 |

示例素材提示词：

> 生成横向 4:3 的无文字科研插图：三个不同来源的匿名数据流汇入同一个存储结构，主体集中在中央，
> 使用平面简洁造型和蓝灰色调，白色背景。四周保留 10% 空白。无中文、英文、数字、坐标、标签、Logo、
> 按钮和仪表盘。此图仅为 PPT 中间区域的插画素材，不要制作幻灯片，不要添加标题或说明。

这只是插画示例；若数据流需要可编辑，应直接做原生流程节点与连接线，而不是生成此图。

## 03-排版设计.md

每页提供一个对象表，所有对象都写明类型、ID、x/y/w/h、z、关联素材、文本或数据。
坐标必须具体到数值，不使用“在上方、字号较大、适当留白”等不能直接组装的描述。

文字对象另列：

- 完整文本、字体名与回退、字号 pt、字重、字色、必要的富文本 runs。
- 横向对齐 left/center/right/justify；纵向 top/middle/bottom；内边距 [上,右,下,左] px。
- 行距倍数、段前/段后 pt、项目符号、缩进、计划换行、最大行数和超长处理。
- 不默认缩小字体适配；先调整文本框或换行，必要时在不损失事实前提下缩写/拆页并同步设计。

图片对象：素材 ID、contain/cover、裁切比例、焦点、透明度、位置和尺寸。科学标注写明连到图中哪里，
裁切修改后重新校对标注位置，不把标签烧进图片。

图形对象：几何形状、填充、描边色/宽、圆角、透明度、层级。连接线：起点/终点对象、连接边、路径、
箭头类型；线放节点后方。形状里的字使用独立文本对象便于修改，表格/图表使用其原生标签。

表格对象：原始二维数据、每列宽、每行高、单元格内边距、表头与隔行色、每列对齐、字体/字号、合并格。
图表对象：类型、类别、系列、原始数值与单位、颜色、坐标范围、轴格式、图例与数据标签、来源说明。

每页末尾列出预期重叠（例如文字覆于标题条）与对齐基准。故意重叠写清理由，不代表忽略实际遮挡。

## 文档与生成物同步

layout.json 是第三份文档的机器副本；其元素 ID 与对象表逐一对应。每次调整文案、字体、布局、素材路径
后都更新 Markdown 和 JSON，再构建。素材文件换版本也保留 ID 及关联页面，避免改错图片。
交付这些设计文件是本工作流的一部分，不把它们当不应交付的内部规划文件。
