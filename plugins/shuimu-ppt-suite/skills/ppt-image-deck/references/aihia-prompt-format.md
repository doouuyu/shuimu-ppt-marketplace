# AIHIA 主体图片提示词格式

每个普通内容页的提示词必须可以单独提交给 `image_gen`。

```text
生成一张 16:9 横版 PPT 主体图片，分辨率 3840×2160。

风格：严格参考 AIHIA 模板的紫色医疗科技视觉；内容页为白色或近白背景，主紫 #6F34A7、亮紫
#7B38CF、深靛蓝 #171447、辅助洋红 #C743DF、电光蓝 #4E5FE7；使用克制的紫蓝渐变、柔性波纹、
数据节点或轻科技光感，中文观感接近微软雅黑或思源黑体，标题与正文层级清晰。不要生成 AIHIA Logo、
集团名称、品牌十字、页码、水印、伪造标识、厚重 3D、廉价霓虹或密集 UI 卡片。

标题栏安全区：顶部 0—240 px 必须严格留空，保持纯白或与主体连续的近白背景；页面标题、Logo、
正文、图标、照片、图表和装饰均不得进入。主体内容从 y≥270 px 开始。不要用横线、阴影、色带、
边框、发光或渐变断层标记标题区域。

版式：<逐项写明主体内容的位置、构图和层级；所有元素均位于安全区下方>

画面文字（不含页面标题）：
<逐字列出正文、标签、数字、表格或图表文字>

所有中文、数字和术语必须逐字准确、完整、清晰可读；直接成为最终成稿。
```

页面标题只写入 `manifest.json` 的 `title` 字段，不得烧录进主体图片。

## 核对

- 顶部 240 px 内完全无内容。
- 图片中没有页面标题和 AIHIA Logo。
- 主体从 y≥270 px 开始。
- 紫色、靛蓝、洋红、电光蓝与白底的比例符合模板。
- 所有文字、数字、缩写和术语与用户材料逐字一致。
