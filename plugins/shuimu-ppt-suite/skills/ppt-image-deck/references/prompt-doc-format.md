# 逐页图片提示词文档 — 格式规范

目标：让文档里**每一段**都能被**直接、单独复制**给图片模型，一次生成一页最终成稿，不依赖后期排版。

## 文档整体

- 首部写使用说明：总页数（如 P01—P67）、「每段为一张独立 PPT 页面的完整提示词，可逐页提交」、
  「为保证一致性每页重复写明统一风格」、「所有中文逐字准确、直接成为最终成稿」。
- 每页之间用 `---` 或二级标题 `## P07｜本页短名` 分隔，便于定位。
- 页面顺序编号 `P01…PNN`；独立章节编号只占一页。

## 每页的 ```text 块结构（四要素，缺一不可）

1. **尺寸声明**：`生成一张 16:9 横版 PPT 图片，分辨率 3840×2160。`（封面/过渡页/表格页可注明页型）
2. **风格前缀**：整段原样重复（各页必须字字相同）。含：定位气质、主色（给出色值）、
   标题/正文颜色、字体、背景、图标风格、装饰克制程度、禁止项（无 Logo/水印/照片/厚重 3D/乱码）。
   有参考图目录时在此引用其路径与参考范围。
3. **版式**：用文字描述**每个元素在页面的位置与构成**——标题在哪、主体用几栏/几宫格/表格几行几列、
   图标画什么、强调色用在哪、留白在哪、底部装饰线等。让「什么位置放什么内容及元素」一目了然。
4. **画面文字**：把该页要出现的文字**逐字列出**（标题、副标题、条目、表格文案等），保持层级清晰。
   文字宁少勿多，保证清晰可读。

> 注意：需求文档若本身写了页码，那是给人看的；**图片内不要出现页码**。（本套流程统一不放页码。）

## 正例（内容页）

````text
生成一张 16:9 横版 PPT 信息图，分辨率 3840×2160。风格：现代医疗政务汇报风，白到冰蓝轻渐变背景，
简约大气、克制专业；主色青绿 #079A95，标题与正文深海军蓝 #0B2E63，辅助浅灰 #F5F7F7；思源黑体或
微软雅黑，青蓝渐变线性图标，充足留白；无 Logo、无水印、无照片、无厚重3D、无乱码，装饰克制、文字优先。
所有中文逐字准确、清晰可读，直接成为最终成稿。

版式：左上角标题「1.1 政策背景与战略机遇」。主体采用 2×2 均衡网格（不做厚重卡片）：每格左侧为青绿色
圆底白色线性图标，右侧两行文字；四个图标依次为 政策文件卷轴 / 医院建筑 / 城市天际线 / 抽象地标。
底部距边缘约 6% 处一条极细青绿色横线。右侧保留较大留白。

画面文字：
1.1 政策背景与战略机遇
· 组织化研究、体系化研发的要求
· 国家紧密型城市医疗集团建设试点政策
· 城市回天地区健康建设指示精神
· 「健康城」战略部署与批示
````

## 反例（要避免）

- ❌ 只写「做一页政策背景」——没有位置、没有图标、没有逐字文字。
- ❌ 风格前缀各页不一致（一页说白底、下一页说深色底）→ 全套视觉割裂。
- ❌ 画面文字塞满几十行小字 → 应拆成多页。
- ❌ 在提示词里要求生成页码、Logo、真实徽标/品牌标志。
- ❌ 用 HTML/表格代码描述版式 → 必须用自然语言描述给图片模型。

## 核对锚点

每页 ```text 块之后追加一行，便于阶段 3 逐字比对，例如：

```
【核对P05】标题=1.1 政策背景与战略机遇；条目=组织化研究/试点政策/健康建设指示/战略部署；无页码无Logo
```
