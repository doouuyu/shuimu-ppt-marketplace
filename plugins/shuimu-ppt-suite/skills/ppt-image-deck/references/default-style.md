# 默认风格前缀（未提供风格文档时使用）

当用户**没有**提供风格文档时，用下面这段作为每页的固定「风格前缀」，逐页原样重复。
若用户口头给了偏好（如某主色、行业气质），先据此微调这段，再固定下来全套统一。

## 默认前缀（可复制）

```text
风格：简约大气、克制专业的现代商务/政务汇报风；白到浅冰蓝的轻渐变背景，充足留白；
主色青绿 #079A95，标题与正文用深海军蓝 #0B2E63，辅助浅灰 #F5F7F7；中文用思源黑体或微软雅黑，
文字锐利清晰；图标用统一的青蓝渐变线性/圆形图标，轻柔光与浅阴影，装饰克制、文字优先。
无 Logo、无水印、无照片堆叠、无厚重 3D、无乱码、无装饰性英文。所有中文逐字准确、清晰可读，
直接成为最终成稿。
```

## 默认版式约定

- **封面**：主标题居中偏上、两行以内、字最大最粗；副标题一行、颜色略浅；左下角放项目信息
  （呈报/编制/日期）；底部一条极细青绿横线。不放 Logo、不放页码。
- **目录**：左上大标题「目 录」；单列等距排列各章，章序号青绿加粗、章名深海军蓝；右侧留白。
- **章节过渡页**：标题组居中偏上，第一行「第N章」青绿大号粗体，第二行章名深海军蓝大号粗体；
  大面积留白，底部极细青绿横线；不放图标。
- **内容页**：左上角本页标题；主体优先「一主一辅」或「左右双栏」或「2×2 网格」，同层级模块
  统一圆角/间距/高度；重点数字用大号深青字配浅青圆角块；每页视觉分组控制在 2–4 个。
- **表格页**：表头青绿底白字，正文白底与极浅灰隔行，细分隔线、宽松行高；文字不缩成小字。

## 统一性要点

- 每页字号层级不超过 3 级；关键词/数字/结论用青绿强调。
- 全套所有页面背景、主色、字体、标题位置保持一致，禁止逐页更换。
- 信息过多时**拆页**，不要塞满小字。
