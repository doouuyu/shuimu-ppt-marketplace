# 像素答辩纯图片提示词前缀

## 固定风格前缀

把下面整段原样写入每一页图片提示词，只替换 `{主题色}`。页面家族写在前缀之后，不改写前缀。
通过 `scripts/check_prompts.py --print-prefix --theme blue` 取得完整前缀，避免手工遗漏色值。

```text
生成一张 16:9 横版 PPT 成稿图片，分辨率 3840×2160。采用正式、严谨、可信的中文科研项目答辩风：
白色或极浅冷灰背景，使用统一的{主题色}建立机构感，按指定页面家族组织信息。保持适度边距、严格网格、
强编号层级和清晰横向阅读顺序。内容页结论先行：在标题下先给出一句完整、可验证的顶部结论句，再用
主图、科研示意图、流程、图表、表格或人物资料组成一个结构化证据矩阵；允许多个证据单元，但必须围绕
同一命题、主次清楚，不做交互式 UI 卡片墙。封面宋体感，正文黑体，数字清楚，关键术语和差异值用少量
红色强调，深色结论条中最多使用一处黄色强调。所有画面文字必须严格依据本页“画面文字”逐字生成，
准确、完整、清晰可读。无来源 Logo、无水印、无页码、无播放器界面、无示例人物、无伪文字、无乱码、
不得生成微小伪文字。风格标识为 PIXEL-ACADEMIC-V2，仅用于提示词识别，严禁绘制该标识。
```


该前缀仅用于纯图片流程；视觉规则由共享风格资源提供。
