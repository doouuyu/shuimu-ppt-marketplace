# 主体图片提示词格式

每页提示词必须能够单独提交给 `image_gen`，至少包含以下内容。

## 普通内容页

```text
生成一张 16:9 横版 PPT 主体图片，分辨率 3840×2160。

风格：参考北京清华长庚医院“水木青绿”视觉体系；深青绿 #3A8F96、墨青 #2C7175、水木绿
#8BBD9C、雾青 #CBE2DA 与白色；现代医疗、学术汇报气质，清爽克制、留白充足，中文观感接近
微软雅黑或思源黑体，轻薄线性图标和克制的建筑线稿。

标题栏安全区：顶部 0—240 px 必须严格留空，保持纯白或与主体连续的极浅背景；页面标题、Logo、
正文、图标、照片、图表和装饰均不得进入。主体内容从 y≥270 px 开始。不要用阴影、下划线、横线、
边框、色带、发光或渐变断层区分标题区域。不要生成任何 Logo、院徽、页码、水印或页面标题。

版式：<逐项写明主体内容的位置、构图和层级；所有元素均位于安全区下方>

画面文字（不含页面标题）：
<逐字列出正文、标签、数字、表格或图表文字>

所有中文逐字准确、清晰可读；无乱码、无伪文字、无厚重 3D、无互联网 UI 卡片堆叠。
```

页面标题只写入 `manifest.json` 的 `title` 字段，不得出现在主体图片提示词的“画面文字”中。

## 无标题栏页面

封面、章节页或结束页设置 `header: false` 时，可使用完整画布，但仍不得让图片模型生成或仿造医院
Logo。若需要医院标识，应继承参考 PPTX 中的原始对象，而不是生成近似标识。

## 核对

- 普通内容页顶部 240 px 内是否完全无内容。
- 安全区底部是否不存在横线、阴影、下划线或明显分隔。
- 图片内是否没有页面标题和医院 Logo。
- 主体是否从 y≥270 px 开始，且文字、数字、术语逐字正确。
