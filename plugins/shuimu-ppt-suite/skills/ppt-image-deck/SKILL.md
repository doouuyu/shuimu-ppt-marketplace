# 纯图片 PPT

## 输入与风格

阅读[共用需求设计](../../shared/design-brief.md)与[选择规则](../../shared/selection.md)。已有完整设计沿用内容与页序；只要设计文档时不生成图片。
选择[风格目录](../../styles/catalog.json)中的资源并查看实际参考；风格名称不切换制作方式。
未指定风格使用清华长庚绿。清华长庚蓝/绿原则上复制原生封面、继承原生标题栏，正文为 Image 图片；用户明确要求全部扁平图片时，说明并执行该范围。

## 生成

生图前先保存完整逐页设计和每页准确提示词。按用户指定页范围执行，不先生成后补设计。颜色需求不触发独立模板建设。

1. 每个页面 ID 对应一页，提取上屏文字，不把制作规则和附录变成页面
2. 每页提示词包含相同 visual_description、版式、配图与准确文字，按所选风格指南使用大图、清晰层级与留白；不把图文混排素材的无字规则带进整页生成
3. 读取 imagegen Skill，逐页使用内置 Image 工具生成。普通图片页生成整页；继承原生标题栏时，只生成对应安全区的正文，不生成重复标题或 Logo
4. 原生封面直接复制和改字，不重新生图。选择其他模板封面或标题栏也属于本流程配置，不建立新的 Skill
5. 图片由 Image 能力绘制，不用代码拼文字、SVG/HTML截图或程序绘图代替。代码仅用于汇总 PPTX、复用原生对象和检查
6. 用 view_image 逐页核对文字、数据、风格、主体尺寸和裁切；只重生成不合格页面

## 组装与核验

无原生叠层时，将已生成的图片按顺序全画幅汇总：

```bash
python "$SKILL_DIR/scripts/build_pptx.py" --images <项目>/images --out <项目>/out/<方案名>.pptx
```

有原生封面/标题栏时，读取 presentations 的模板复用与本地 API 文档，导入所选模板、复制源页，在标题栏下方安全区插入正文图。
保留实际 Logo、标题栏与封面对象；不让图片覆盖品牌结构。可参考[原生标题栏组装工具说明](references/native-assembly.md)。
最终按真实播放顺序重导入并渲染检查，封面/标题栏与源页对照。交付时说明图片主体内部不可逐项编辑，以及保留的原生对象范围。
