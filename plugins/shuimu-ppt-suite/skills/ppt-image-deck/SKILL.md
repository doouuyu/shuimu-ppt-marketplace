# PPT Image Deck（图片版 PPT 端到端生成）

把一份**需求文档**变成一套**以图片为每页**的 PPT：先写逐页图片提示词文档，再逐页调用内置
`image_gen` 生成 4K 图片，逐页与需求文档核对，最后汇总成 `.pptx`。

**硬性规则（贯穿全程）：**
- **每页图片只能由 AI 图片模型（内置 `image_gen` 工具）生成，严禁任何程序式/代码式绘图。**
  禁止用 Pillow/PIL、matplotlib、OpenCV、Canvas、SVG→位图、HTML/CSS 截图、`python-pptx`
  画文本框、或任何脚本把文字/图形拼合成图片。文字和版式必须由图片模型直接画进图里。
  代码只允许出现在**最后一步的 PPTX 汇总**（`build_pptx.py`，仅把已生成的整张图片贴进幻灯片，
  不绘制任何内容）。
- 每页尺寸固定 **16:9、3840×2160**。图片里**不放页码、不放 Logo/院徽/水印**。
- 全套**风格必须统一**：所有页面复用同一段「风格前缀」。有风格文档以文档为准，否则用
  `references/default-style.md`。
- 画面文字要**逐字准确、清晰可读**；文字不要太多，宁可拆页也不要塞满小字。

## 输入

- **必需**：需求文档路径（Markdown/文本，含内容与页面结构）。
- **可选**：风格文档路径（如《…PPT 风格规范》）。有则其风格/母版为唯一视觉依据。
- **可选**：参考图目录（用于统一视觉，在提示词里以路径引用）。
- **可选**：输出项目根目录（默认取需求文档所在目录）。产物落在其下 `images/` 与 `out/`。

开始前若这些路径未给全，先问清需求文档路径与是否有风格文档；其余可用默认值，无需追问。

## 工作流

### 阶段 1 — 生成逐页图片提示词文档

1. 通读需求文档，切分页面：**一个逻辑段 = 一页**（封面、编制说明、目录、章节过渡页、
   每个内容点各一页）。独立章节编号页只占一页。为页面顺序编号 `P01…PNN`。
2. 确定「风格前缀」：
   - 有风格文档 → 从中提炼出一段可复用的固定前缀（含主色/字体/背景/母版标题栏/禁止项），
     并严格遵守其几何与颜色约束。
   - 无风格文档 → 使用 `references/default-style.md` 的默认前缀（简约大气、青绿科技政务风）。
3. 为**每一页**产出一个独立 ` ```text ` 代码块，块内至少包含四部分（详见
   `references/prompt-doc-format.md`）：**①尺寸声明 ②风格前缀（每页原样重复）③版式：写清每个
   元素放在页面什么位置、含什么图标/图形 ④画面文字：逐字列出**。每块都要能直接单独复制给图片模型。
4. 每页末尾附一行**核对锚点**（该页画面文字的逐字清单摘要），供阶段 3 机器化比对。
5. 保存为 `PPT图片生成提示词_<YYYYMMDD>.md`，放在项目根目录。首部写明总页数与「每段=一页、
   可逐页提交」的使用说明。

产出后**先自查**：页数是否与需求文档章节吻合、有无缺页/错字/重复、风格前缀是否每页一致。

### 阶段 2 — 逐页生成图片

1. 每页**只允许**用**内置 `image_gen` 工具**生成整张图片；不是 CLI、不是 HTML、不是任何
   代码绘图库。**一页一次调用**，尺寸 `3840x2160`，质量取 `high`（文字/图表密集页尤其如此）。
2. 直接把该页 ` ```text ` 块内容作为提示词提交。要求模型把画面文字逐字、清晰渲染。
3. 保存到项目 `images/` 下，**用零填充序号命名**：`01.png`、`02.png` …（位数与总页数一致，
   例如共 67 页则两位）。把生成结果从默认路径移动/复制进项目 `images/`，不要只留在
   `$CODEX_HOME/generated_images/`。
4. 按 `P01…PNN` 顺序逐页推进，不要用一次多变体（`n`）替代不同页面。

### 阶段 3 — 逐页核对（验收）

对每一张图片，用 `view_image` 打开后逐项核对，标准如下：

- **文字逐字一致**：与需求文档 / 该页「画面文字」完全一致，无错字、漏字、多字、乱码、伪文字。
- **内容正确**：该页要点齐全，数字/表格/术语无误。
- **风格统一**：主色、字体、背景、母版标题栏（若有风格文档）与其余页面一致。
- **禁止项检查**：无页码、无 Logo/水印、文字未被图形遮挡、未贴边；整页须是图片模型直接
  生成，无程序拼贴/截图/代码绘图痕迹（如生硬的等宽字体贴图、像素对齐的纯色文本框）。

只对**不合格的页**按序号重新生成并覆盖对应 `NN.png`（做单点修改后再复检），合格页不动。
把每页核对结论汇总成一份简短清单反馈给用户。

### 阶段 4 — 汇总为 PPTX

全部图片核对通过后，把当前 `ppt-image-deck` Skill 的根目录解析为 `SKILL_DIR`，再运行脚本汇总：

```bash
python "$SKILL_DIR/scripts/build_pptx.py" \
  --images <项目>/images \
  --out    <项目>/out/<方案名>.pptx
```

脚本把 `images/` 下的图片按数字顺序，每张作为**一张全画幅 16:9 幻灯片**（无边距、无留白）
插入，输出到 `out/`。缺依赖时脚本会尝试自动安装 `python-pptx`。

（可选）若环境有 LibreOffice，可加 `--pdf` 同时导出 PDF；没有则跳过并告知用户。

完成后报告：提示词文档路径、图片张数与目录、最终 `.pptx`（及 PDF）路径、以及任何重生成过的页码。
