# 蓝橙块状图片版视觉规范

本规范只定义视觉风格。用户提供的需求文档、内容稿和数据是唯一内容来源；示例参考图中的文字有问题，
不得复制、猜测、修正或沿用参考图中的任何文字、数字、机构名、产品名和结论。

## 固定风格前缀

把下面整段逐字重复到每一页图片提示词中：

```text
生成一张 16:9 横版 PPT 成稿图片，分辨率 3840×2160。整体为现代、清晰、理性、可信的商务科技汇报风：
纯白或近白背景，蓝色为绝对主色，橙色只作重点强调；以大面积矩形、圆角矩形、横向条带、双栏和网格
信息块组织内容，少图标、多色块，边界清楚，网格对齐，留白充足。主蓝 #1769B0，深蓝 #0B3A75，
浅蓝 #EAF3FF；强调橙 #E8941A，浅橙 #FFF1D8；标题和正文用近黑 #101820，辅助文字用灰蓝 #526579。
中文使用思源黑体或微软雅黑，标题粗体、正文中等字重，文字锐利清晰。每页默认 0–2 个简洁线性图标，
确有必要时最多 3 个；图标只辅助识别，不成为视觉主体。色块可用轻微同色渐变，但不得炫光、玻璃拟态、
厚重阴影或立体 3D。无 Logo、无院徽、无水印、无页码、无照片拼贴、无印章徽章、无伪文字、无乱码、
无装饰性英文。所有画面文字必须严格依据本页“画面文字”逐字生成，准确、完整、清晰可读，直接成为最终成稿。
```

## 配色比例

- 白底与留白占页面约 55%–75%，保持清爽、明亮和易读。
- 蓝色承担约 70%–85% 的彩色面积，用于主标题标记、核心模块、流程主线和结论块。
- 橙色承担约 15%–30% 的彩色面积，只用于关键数字、对照项、风险、行动或重点结论。
- 正文优先用近黑或深蓝，不使用大段橙色正文，不使用蓝橙渐变文字。
- 同层级模块保持同色；蓝橙用于表达层级、对照或重点，不随机交替。

## 块状构图规则

- 每个内容页优先使用 2–6 个大信息块，不堆叠十几个小卡片。
- 使用明确的矩形网格、轻圆角矩形、横向标题条、全宽结论条和分区底色。
- 块间距保持一致；同排模块等高，同列模块对齐，边距宽松。
- 色块应承载标题、数字、简短结论或一组相关要点，而不是纯装饰。
- 阴影只允许极浅的冷灰软阴影；边框优先 1–2 px 浅蓝灰，避免粗重描边。
- 复杂关系优先拆成“标题块 + 2–4 个步骤块 + 结论块”，避免复杂环形箭头和中心徽章。

## 图标约束

- 默认每页 0–2 个图标；最多 3 个。
- 仅在图标能够降低阅读成本时使用，采用单色蓝或橙的简洁线性图标。
- 不为每条文字都配图标，不使用成排圆形图标，不使用拟物 3D 图标。
- 不生成印章、认证章、奖章、医院 Logo 或类似真实品牌标识的图形。

## 推荐版式

### 封面

白底；主标题居中或左对齐，占上半区；用一条蓝色大色块或蓝橙组合横条建立识别；副标题和日期放在
较小的浅蓝信息块中。最多一个抽象几何装饰，不放图标阵列。

### 目录与章节页

目录用 3–5 个横向编号块或纵向章节块；章节页用大号蓝色章节编号、深色章节名和一个橙色短条。
保持大面积白底，不使用照片。

### 双栏对照页

左侧主蓝块、右侧橙色或浅橙块；块内用白字或深色字，层级一致。适合问题/答案、现状/目标、
能力/价值、内部/外部等对照关系。

### 流程页

使用 3–5 个横向或纵向矩形步骤块，以细蓝线或短箭头连接。只给关键节点使用 1–2 个小图标，
不做复杂环形流程，不使用中央徽章。

### 矩阵与多模块页

使用 2×2、3×2 或“一主两辅”块状网格。核心模块用深蓝，辅助模块用浅蓝；仅一个重点模块使用橙色。

### 数据与结论页

大数字放入蓝色或橙色数字块，图表使用蓝色序列并以橙色突出一个重点。底部用全宽蓝色结论条收束，
结论文字保持一句话。

## 字体与信息密度

- 4K 页面主标题建议 72–96 px，二级标题 46–60 px，正文 30–42 px，标签 28–36 px。
- 每页字体层级不超过 3 级；每个信息块优先 1 个短标题加 1–4 条短句。
- 标题过长时合理换行，但不得截断；正文过多时拆页，不缩小到难以阅读。
- 中文标点、数字、英文缩写和专有名词必须与用户材料逐字一致。

## 禁止项

- 禁止复制参考图中的示例文字或根据其错误文字推断内容。
- 禁止使用大面积深色背景；章节页也应保持白底为主。
- 禁止密集图标、照片墙、人物剪影、复杂插画、装饰性 3D 和玻璃拟态。
- 禁止复杂环形箭头、金属徽章、印章、认证标识和无来源 Logo。
- 禁止随机改变主蓝、强调橙、圆角大小、标题位置和模块间距。
- 禁止为了塞下文字而使用小字；应先压缩文案或拆页。

## 逐页视觉核对

每页必须同时满足：白底、蓝色为主、橙色为辅、少图标、多色块、对齐清晰、留白充足、文字逐字准确。
任一项不满足都应重生成该页，不得通过程序拼贴或覆盖修补。
