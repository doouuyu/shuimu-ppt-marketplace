# 提示词检查与风格校准

## 先固定整套骨架

默认蓝色使用 style-contract 中的机构蓝、黑体正文、宋体感封面、红色关键词。普通内容页达到 3 页时，
至少 60% 使用全宽顶部标题条；其他内容页可用左上编号锚点。胶囊和人物标签栏只用于对应子系列。
有章节过渡时默认复用提纲 A，切换当前章节；不默认使用“大号 01 + 单条蓝色横幅”。
不强行补目录或增加用户限定的页数。没有足够证据时保持简洁，不编造论文/证书来凑密度。

标题条推荐 x=3%、y=3%、w=94%、h=9%；结论句 y=14%、h=10%；主体 y=26%–86%；
底部有结论时放 y=89%、h=7%。封面标题使用宋体感，占高16%–28%，底部同色波带占高8%–15%。
这些比例作为默认坐标锚点，按长标题和真实内容调整，不能变成缩小文字的理由。

## 每页代码块

使用 `## P01｜标题` 形式的章节头，每页只有一个 text 代码块。先粘贴脚本输出的完整前缀，再写：

```text
页面角色：content
页面家族：背景/差距页
标题系统：全宽顶部标题条
密度级别：密
版式：顶栏 x=3%、y=3%、w=94%、h=9%，编号与标题白字；结论 y=14%；下方左文35%右图65%。
证据图版：左侧列出用户材料里的两项限制，右侧放用户提供的数据表与流程对照，共同支撑结论。
顶部结论句：只填写用户证据支持的判断；不足以形成判断时写“无”，不得编造。
画面文字：
1.1 数据治理现状
此处填写经过核对的逐字文案
```

该片段是字段示例，单独不构成合格提示词；前面必须包含完整风格前缀。封面、目录、结束页可写
`标题系统：专用页`、`证据图版：无`。内容页结论为“无”时使用客观主题说明，不凭空升级为科研结论。

## 生成与检查

1. 对全部提示词运行 check_prompts.py。它检查每页完整前缀、主题一致、页面编号、必要字段、内容编号
   和标题系统比例。错误必须逐页修正，不通过删除检查或替换标识绕开。
2. 实际 image_gen 调用直接使用已检查的代码块。额外内容只能是对应用户素材的参考范围说明。
3. 先生成封面和一张典型内容页，有目录时再生成一张目录。自检通过即继续，不默认增加用户确认步骤。
4. 将成稿与保留参考拼图并排观察：标题条高度与编号、宋/黑字体差异、图文占比、红色关键词、波带和
   目录轮廓。不能只因为“蓝白配色、字清楚”就判合格。
5. 检查内容页的主视觉是否为证据图版。如果变成均匀圆角 UI 卡片、橙色 KPI、装饰数据库球体或大面积
   留白，回到具体页面的版式描述修正。无需禁止科学内容本身需要的图形。
6. 原始拼图含示例文字与品牌，不直接交给图片模型。首批合格的原创页面可作为后续同角色页面的视觉
   参考，明确只借用几何、字体与配色，文字仍以该页画面文字为准。首批反复偏离时，可先用 image_gen
   生成无品牌的通用学术布局参考并视觉验收，不能使用代码把一整页画成图片。
   现有 `assets/calibrated-content-example.png` 是此流程生成的原创无品牌蓝色内容页，可传给图片模型
   作为视觉锚点；它展示“可编辑 PPT 制作流程”只是示例，不是未来文案来源。绿色/红色版本需要替换
   主题色说明，不直接照搬该图的蓝色。该锚点用于内容页，不能替代宋体封面和竖向提纲参考。
7. 每页记录提示词文件和实际生成版本，便于追溯；不允许只修文档而继续使用旧的错误图片。

提示词检查不检测图片中的错字、密度和事实；最终仍须逐页视觉核对。检查工具不会自动重新写入内容。
