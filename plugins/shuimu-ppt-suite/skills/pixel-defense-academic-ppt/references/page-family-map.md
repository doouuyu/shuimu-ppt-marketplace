# 页面家族与叙事映射

本文件定义如何把用户内容映射到全量参考库中反复出现的页面家族。先判断叙事任务，再选版式；不要为了
“像参考图”而复制示例内容，也不要机械轮换页面。

## 页面家族选择矩阵

| 叙事任务 | 首选页面家族 | 密度 | 核心结构 |
|---|---|---:|---|
| 建立项目身份 | 封面 A/B/C | 轻 | 大标题 + 副标题 + 汇报信息 + 主题色底带 |
| 告知整体结构 | 提纲 A/B/C/D | 轻/中 | 4–6 个章节，只突出当前章节 |
| 解释国家需求或研究背景 | 背景/差距页 | 密 | 顶部结论句 + 趋势/现状证据 + 底部判断 |
| 说明关键问题 | 卡脖子/痛点页 | 中/密 | 问题拆解 + 成因 + 影响或差距 |
| 说明研究目标 | 目标/任务页 | 中 | 总目标 + 2–4 个分目标 + 对应指标 |
| 解释原理或机制 | 中央主图页 | 密 | 中央机制图 + 两侧注释 + 单向因果链 |
| 展示技术路线 | 路线/流程页 | 密 | 3–6 步流程 + 输入/输出 + 阶段结果 |
| 比较方案或现状 | 多列比较页 | 中/密 | 2–4 列同构证据 + 一个结论 |
| 展示数据 | 图表/表格页 | 密 | 主题色表头或图表 + 1–3 个红色重点值 |
| 展示成果 | 成果矩阵页 | 中/密 | 论文/专利/产品/奖项证据 + 数量总结 |
| 介绍个人或负责人 | 人物页 | 中 | 一张授权头像 + 履历 + 代表成果/指标 |
| 介绍团队 | 团队页 | 中 | 负责人 + 3–8 名成员 + 角色/能力 |
| 展示平台条件 | 平台/保障页 | 中 | 场地/设备/合作/经费 2–4 区 |
| 呈现风险与计划 | 风险/计划页 | 中 | 风险—影响—应对，或阶段—里程碑—产出 |
| 收束演讲 | 结束页 | 轻 | 一句正式结束语 + 汇报信息 + 同色波带 |

## 三种封面

### 封面 A：白底机构型

- 使用大面积白底、居中或左对齐的主题色宋体感标题、细横线与底部低矮波带。
- 适合青年基金、人才计划、重点研发、实验室建设与一般项目申报。
- 只放标题、副标题、汇报人、单位和日期；不要在封面塞摘要、目录或成果数字。

### 封面 B：深色横幅型

- 页面中部或上半部使用深蓝/深绿/深红大横幅，标题用大号白色宋体感文字。
- 上下保留白色信息带，可放学科、项目类别和汇报人。
- 适合科技奖励、正式评审与强调机构级项目；同一套中只使用一种深色主题。

### 封面 C：色带与场景型

- 使用主题色波带、建筑或场景的低对比度蒙版，以及居中的白色或主题色大标题。
- 适合人才项目、区域基金与有明确单位场景的汇报。
- 场景只作背景，不抢标题，不生成来源品牌建筑或未经授权的单位标识。

## 四种提纲

### 提纲 A：左侧竖向栏

- 左侧 25%–34% 为深色竖栏，竖排“汇报提纲/汇报内容/答辩提纲”；右侧列 4–6 个编号横条。
- 当前章节使用红色或深主题色，未激活章节使用主题色浅阶或灰色。
- 适合章节较多、需要重复出现章节过渡的整套汇报。

### 提纲 B：中央窗口

- 页面中心放白色或半透明矩形窗口，左侧小型竖栏，右侧 3–5 个横向章节条。
- 背景使用极淡建筑、道路、波纹或几何纹理，底部有细线或低矮波带。
- 适合正式项目申报和重点实验室建设。

### 提纲 C：四栏提纲

- 顶部居中写“目录/汇报提纲”，下方放 4 个等宽竖列；当前章节红色，其余为主题色或灰色。
- 底部用对称波带收束，页面留白充足。
- 适合个人、主要成绩、未来计划、支持平台等四段式人才/基金答辩。

### 提纲 D：二维章节表

- 使用 2×2 或横向 4 格的大章节块，每块只有编号、短章节名和极少辅助字。
- 适合章节名称较长或需要同时展示全局结构的汇报，不用于每个章节过渡页。

四种提纲只选择一套作为整份 PPT 的主提纲样式；后续章节过渡重复同一轮廓并切换激活项。

## 内容页标题系统

### 系统 1：全宽顶部标题条

- 深主题色横条占页面高度约 8%–11%，左侧为 `1.1/2.3` 编号与标题，标题白色粗黑体。
- 用于大多数研究、成果、团队和平台页，是最稳定的默认内容标题系统。

### 系统 2：左上编号锚点

- 白底保留，左上用短竖线、编号或小色块配细横线；标题使用主题色深字。
- 用于资料更精炼、证据图较大的页面，避免全套过于沉重。

### 系统 3：圆角标题胶囊

- 顶部使用深主题色圆角长条，左侧带 `01/02/03` 编号，右上保留干净空间。
- 用于人才支持、工作计划、个人成果等较现代的子系列；不要与全宽标题条随机混用。

### 系统 4：人物页顶部标签栏

- 顶部以 3–4 个小标签标记“个人简介/学术成果/计划工作/研究条件”等章节。
- 当前标签用主题色，其他标签降为浅色；正文仍保持一个主标题与一个证据结构。

## 证据图版

内容页先写顶部结论句，再从下列版式选择一个；不要把多种版式同时堆在一页。

### 图版 A：左文右图

左侧 35%–45% 放问题、定义或判断，右侧放一张主图或一组同构证据；适合背景、现状和应用页。

### 图版 B：中央主图 + 两侧注释

中央主图占主体 45%–60%，两侧各 1–3 个短注释；适合原理、机制、装置和系统架构。

### 图版 C：三列或四列比较

各列使用相同结构比较不同阶段、方法、对象或能力；顶部使用共同表头，底部写统一判断。

### 图版 D：两行证据矩阵

上排呈现现状/问题，下排呈现方案/结果；通过箭头、共同底色或垂直侧栏形成因果关系。

### 图版 E：表格 + 证据

上半部为表格或指标，下半部为论文、证书、产品、设备或场景证据；适合成果综述、项目承担和奖项。

### 图版 F：流程/技术路线

使用 3–6 个连续阶段，箭头单向、连接词明确；每个阶段只放一个短标题和一个主要输出。

### 图版 G：垂直侧栏

在图版 A–F 左侧或右侧增加主题色垂直侧栏，写“研究内容/关键技术/研究方法/基础设施不足”等短标签；
侧栏不超过页面宽度 12%，不放长段正文。

## 专用页面

### 人物与负责人

使用一张授权头像作为唯一人物主图，旁边排列履历、研究方向、代表成果和 3–5 个大数字。不要生成证件照、
假证书或头像墙；用户未提供照片时使用明确头像占位。

### 团队

负责人优先，成员按角色或任务分组。人数多时只保留用户提供的核心成员与角色，不制造模糊小头像。

### 成果

把成果分为论文/专利/标准/产品/应用等 2–4 组；大数字与证据对应。国际成果页可使用论文或会议证据，
但不得生成无法核对的英文段落。

### 平台与保障

按依托单位、实验条件、设备、合作平台或经费分区，图片保持矩形，使用主题色小标题和统一底线。

### 风险与计划

风险页使用“风险来源—影响—应对”；计划页使用“阶段—里程碑—产出”。不要用无含义装饰性流程。

### 结束页

使用白底 + 同色波带或深色横幅，大号正式结束语居中。结束语之外只保留汇报人和单位；不重复摘要。

## 三套叙事序列

### 人才/基金答辩

封面 → 四种提纲中的一套 → 个人与工作经历 → 主要学术成果 → 拟开展的研究 → 服务国家战略/工作计划
→ 支持保障平台 → 工作发展潜力或风险 → 正式结束页。

### 科技奖励/项目申报

封面 → 提纲 → 国家重大需求/研究现状 → 卡脖子问题与差距 → 目标与总体思路 → 主要创新点/关键技术
→ 研究内容与机制 → 国际国内成果 → 应用推广与经济社会效益 → 团队/平台 → 正式结束页。

### 重点实验室建设

封面 → 提纲 → 战略定位与国家需求 → 历史贡献与现状 → 重点任务 → 实验室重组主要措施 → 团队组成
→ 平台条件与重大项目 → 建设计划、风险和保障 → 正式结束页。

用户材料不满足某个环节时直接省略，不编造补齐。每个章节先提出问题或判断，再给证据，再在必要时收束。

## 版式节奏与选择规则

1. 先确定整套叙事序列，再给每页一个唯一叙事任务。
2. 为每页选择一个标题系统和一个证据图版；人物、提纲、封面和结束页使用专用家族。
3. 连续两页不要同时复用完全相同的列数、主图位置和证据轮廓；章节过渡页除外。
4. 连续密集证据页达到 3–4 页时，插入一页中密度总结、章节过渡或大图页形成呼吸。
5. 内容不足时扩大主图与留白，不增加无来源图标；内容过多时拆页，不缩成微小文字。
6. 标题系统在同一章节内保持稳定；若使用圆角标题胶囊或人物页标签栏，应作为完整子系列连续使用。
7. 所有页面最终回到同一主题色、字体层级、边距、编号规则和底部收束方式。
